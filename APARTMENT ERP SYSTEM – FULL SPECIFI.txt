3.3 Auto Calculation Rules

ใช้น้ำ = น้ำหลัง - น้ำก่อน
ใช้ไฟ = ไฟหลัง - ไฟก่อน

รวมค่าน้ำ = (ใช้น้ำ × ค่าน้ำต่อหน่วย) + ค่าบริการมิเตอร์น้ำ
รวมค่าไฟ = (ใช้ไฟ × ค่าไฟต่อหน่วย) + ค่าบริการมิเตอร์ไฟ

รวมเงิน =
ค่าเช่า + รวมค่าน้ำ + รวมค่าไฟ + เฟอร์ + อื่นๆ

แต่ทุกค่าอนุญาต override ได้

3.4 Billing Version System

BillingPeriod (เดือนเดียวกัน)

→ สร้าง v1 (Active)

→ สร้าง v2
→ v1 inactive
→ v2 active

Upload ครั้งที่สาม:
→ v3
→ v2 inactive
→ v3 active

3.5 Restore Version

Owner สามารถ Restore version เก่าได้

เมื่อ Restore v1 ขณะที่ active คือ v3:

ระบบจะ:

Clone v1 → สร้าง v4

v4 = Active

v3 = Inactive

v4.isRestoredFrom = v1

ไม่ flip flag ตรง ๆ
